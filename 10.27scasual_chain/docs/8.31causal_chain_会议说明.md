# 8.31causal_chain 会议说明

足球赛事因果链编排（拆条 + 集锦）。本版不含五佳球 / 十佳球 Top-N。

---

## 1. 代码介绍

### 做什么

| 模块 | 路径 | 能力 |
|------|------|------|
| 拆条因果链 | `algo/causal_chain6` | 结果链 / 修正链 / 险情链 / 特殊链；离线拆条 + 在线流式拆条；Qwen 可选 |
| 集锦因果链 | `algo/causal_chain8` | 选片 → 分类/精炼 → 集锦片段；图边：`follow` / `same_sequence` / `correction_of` |

### 流程

```
Event / Timeline
  ├─ Offline → causal_chain6 strip
  └─ Online  → OnlineStripEngine
                    ↓
             Strip Causal Chains
                    ↓
             causal_chain8
                    ↓
             Highlight Clips / Highlight Chain
```

- 离线：整段输入一次出链。
- 在线：按事件到达推进，任意时刻禁止使用未来事件。
- 集锦逻辑完整率评的是 **highlight clips**（选片后再分类），不是 P5 全量图节点。
- P5 图（`link_strip_chains`）只做结构回归：节点完整、无环、排序、修正边方向。

### 目录

| 路径 | 说明 |
|------|------|
| `algo/causal_chain6` | 拆条算法（`strip_pipeline`、`online_strip_engine`） |
| `algo/causal_chain8` | 集锦算法（`select_moments`、`refine`、`link_strip_chains`） |
| `eval` | 四个正式评测入口 |
| `datasets` | 63 场测试数据 |
| `reports` | 评测 JSON |
| `README.md` | 跑法、口径、字段说明 |

### 怎么跑（rule-only，默认）

服务器包路径示例：

`/vepfs-cnbj0623a0102d84/archive/qinghua/causal_chain2/8.31causal_chain`

```bash
cd 8.31causal_chain
export PYTHONPATH=$PWD/algo:$PWD/eval
python eval/run_causal_chain_selftest.py          # 全量 63 场
python eval/run_causal_chain_selftest.py --limit-matches 2   # 调试
```

分项：

```bash
python eval/eval_offline_strip.py --event-source gold_events
python eval/eval_offline_highlight.py
python eval/eval_online_strip.py --stream-source gold_events
python eval/eval_online_highlight.py --stream-source gold_events
```

默认不开 Qwen。已有环境可用 `causal_env/bin/python`，不要把 `PYTHONPATH` 设成外层旧包。

### 逻辑完整率口径

一对一 strict，四条同时满足：

1. 时间区间有交叉
2. category 相同
3. first_event 相同
4. last_event 相同

一条预测最多配一条 gold。

### 当前全量结果（rule-only，63 场）

| 任务 | Gold | Matched | Logic Rate | Precision |
|------|------|---------|------------|-----------|
| 离线拆条 | 437 | 359 | **82.15%** | 93.01% |
| 在线拆条 | 437 | 313 | **71.62%** | 72.79% |
| 离线集锦（全部） | 172 | 105 | **61.05%** | 61.05% |
| 离线集锦（人工标注） | 114 | 65 | 57.02% | — |
| 在线集锦（全部） | 164 | 0 | **0%** | 0% |

在线拆条时延：P50=60s，P90=167.4s，超过 45s 的比例 68.05%。

P5 结构（不要叫逻辑完整率）：离线 63/63 通过，在线 60/60 通过；无丢节点、无重复、无环、排序与修正边方向正常。

Qwen 在线拆条 strict 71.85%，相对规则仅 +0.23 个百分点，默认仍用 rule-only。

## 2. 数据集介绍

有测试集，已打进包，路径 `datasets/`。

| 项 | 规模 |
|----|------|
| 比赛 | 63 场 |
| 拆条 gold | 437 条 |
| 拆条类别 | 险情 218 / 结果 160 / 特殊 48 / 修正 11 |
| 集锦 gold | 正式评测优先 `highlight_gold_no_t2`；标签来源约人工 114 + 启发式 58 |
| 过滤 | 去掉回放、空类别 |

每场目录 `datasets/matches/<场次>/`：

| 文件 | 内容 |
|------|------|
| `timeline.json` | 整场事件（类型 + 时间） |
| `strip_gold.json` | 拆条人工链 |
| `highlight_gold_no_t2.json` | 集锦 gold（正式优先） |
| `highlight_gold.json` | 上者别名 |
| `highlight_gold_with_t2.json` | 含 T2 的集锦 gold |
| `meta.json` | 场次元信息 |

索引：`datasets/index.json`。由 `scripts/build_datasets.py` 从交付数据生成。

集锦 gold 的 `label_source`：

- `annotation`：邻近人工标注补类别和首末事件
- `timeline_heuristic`：没有可靠标注时，用时间线启发式

正式拆条自测用 **gold_events**（因果链单模块）。整场 timeline 可测 detector→因果链端到端，但存在漏检、错型和时钟对齐问题。

## 3. 其他说明

### 怎么读评测 JSON

主文件：`reports/causal_chain_selftest_summary.json`，先看 `summary_table`。

| 字段 | 含义 |
|------|------|
| `gold` | gold 条数（分母） |
| `matched` | 一对一 strict 命中数 |
| `logic_rate` | 逻辑完整率 = matched / gold |
| `precision` | 命中 / 预测条数 |
| `latency_p50` / `latency_p90` | 在线首次命中时延（毫秒） |
| `over_45s_rate` | 时延超过 45 秒的比例 |
| `annotation_only` | 只统计人工标注 gold |
| `timeline_heuristic_only` | 只统计启发式 gold |
| `p5_structural.pass_rate` | 图结构通过率，不是逻辑完整率 |

`logic_complete_rate = null` 表示这批没有有效集锦 gold，只报结构，不能写成逻辑完整率。

分项文件：`reports/eval_offline_strip.json`、`eval_offline_highlight.json`、`eval_online_strip.json`、`eval_online_highlight.json`。

### 已知限制

- 在线时延受窗口参数（`post_ms` / `window_ms`）影响
- 在线集锦逻辑完整率当前为 0，待优化
- timeline 不适合当单模块金标准，正式自测用 gold_events
- 本版不做 Top5 / Top10
