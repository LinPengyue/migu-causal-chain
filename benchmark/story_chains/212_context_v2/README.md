# 212条故事链：全场上下文重构 v2（2026-11-23）

**本目录与产品算法及Gold标注分离。** 共212条候选故事链、94场比赛。此处发布的是可复核的**公开格式预标注**，不是经过真实视频首次直播核验的Benchmark金标。

- 数据：`part_001_020.jsonl` ... `part_201_212.jsonl`，共212行，每行一个故事对象，按片段顺序排列；全量JSON、94场逐场JSON在本次对话交付ZIP中。
- 数据结构：`schema_version=migu_story_chain_segments_v2`；每条故事有 `chain_category`、`story_chain_subtype`、`story_title`、按证据提炼的 `story_summary`、`segments`。所有 `segments` 仅为 `source_event` 或 `source_chain` 引用，记录源归档、文件名、ID、媒体起止秒。
- 重构：遍历原始事件与短程链，补充片段发生前后的进攻/防守、重要动作和后续比赛进展，不要求固定5段，不把所有普通传球塞进故事。关键转折四子类更新为「判罚争议与战局转折」「红牌冲击与攻守重构」「定位球战术执行与破局」「攻守转换与关键破门」。
- **时间校正**：短链内部事件的 `bz_id` 与原子事件关联，片段起止时间取链接事件的原始 `media_time` 范围，不直接把可能属于另一时间轴的 `segment_time_video` 当作播放器时间。不得凭内部 `event_id` 直接跨文件连接。
- 非回放筛选：排除标记为回放/慢动作的源事件，进一步排除注释明确标记为回放、集锦、历史片段的事件。**这些仍只是元数据检查，不等于 FIRST_LIVE 视频验证**。
- 片段关系仅包括时间/叙事连接（`same_broadcast_sequence`、`later_narrative_development`、`contrasting_attack`），不能默认作为严格因果边。
- 公开数据JSON不混入 `DRAFT`、`UNVERIFIED`、审核意见等内部字段。审阅操作规范由 `审核方法.md` 另存。
